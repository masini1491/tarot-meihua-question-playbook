## 類型

Tarot API，提供完整牌組、牌義資料與常見 spread endpoint，例如 random card、three cards、Celtic Cross。

## 值得吸收

### REFERENCE-ONLY — Data / spread / interpretation 分層

來源把：

- card data
- spread endpoint
- interpretation fields

分成不同層次。對本 Playbook 的啟示是：

> 「牌是什麼」與「這張牌在此牌位負責回答什麼」應分開。

這支持本 Repo 的 Position Contract 原則，但不直接提供 question-design governance。

## 不直接採用

- 不把其 API endpoint 數量或固定 spread 視為本 Playbook 標準。
- 不複製其牌義資料來源。
- 本 Repo 不以建立牌義 API 為目標。
