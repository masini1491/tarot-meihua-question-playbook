## 類型

塔羅 API，提供完整牌組、牌義資料與常見牌陣端點，例如隨機單牌、三牌與凱爾特十字。

## 值得吸收

### REFERENCE-ONLY｜僅供參考 — 資料／牌陣／解讀分層

來源把：

- 牌面資料
- 牌陣端點
- 解讀欄位

分成不同層次。對本手冊的啟示是：

> 「牌是什麼」與「這張牌在此牌位負責回答什麼」應分開。

這支持本 Repo 的牌位契約原則，但不直接提供題目設計治理。

## 不直接採用

- 不把其 API 端點數量或固定牌陣視為本手冊標準。
- 不複製其牌義資料來源。
- 本 Repo 不以建立牌義 API 為目標。
