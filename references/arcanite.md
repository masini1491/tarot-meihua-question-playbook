## 類型

Python 塔羅解讀引擎，將解讀分成兩層：

1. **結構化組裝（deterministic assembly）**：依牌位與整理過的牌義資料組出結構化內容。
2. **可選的 LLM 敘事整合（optional LLM synthesis）**：再由 LLM 做整體敘事。

它也提供問題分類、不同牌陣、牌位特定解讀與依問題背景變化的牌義資料。

## 值得吸收

### ADAPTED｜調整後採用 — 先分類問題，再選牌陣

Arcanite 會先辨識問題類型，並讓牌義依背景與牌位變化。

本手冊吸收為：

> 不要先決定抽幾張才硬塞問題；先辨識比較／時間／流程／人物／原因等題型，再選牌陣。

### ADOPTED｜已採用 — 牌位語意必須先於 LLM 敘事

它的結構化層先依牌位取得對應解讀，再交給 LLM 做敘事整合。

本手冊吸收為：

> 牌位契約是上游權威；敘事只能整合已定義的牌位證據，不能在最後改寫牌位功能。

### ADAPTED｜調整後採用 — 先結構，後敘事

本手冊進一步泛化成：

1. 先固定問題、牌陣與牌位。
2. 先做逐位置與整組結構判讀。
3. 最後才產生整體故事。

目的：避免先有結論再挑牌義支持。

## 不直接採用

- 本 Repo 不需要複製 Arcanite 的完整牌義資料庫、RAG 結構或 PDF 產出流程。
- 問題分類只當作題型路由，不代表 AI 自動分類永遠正確；高歧義問題仍應人工拆解。
